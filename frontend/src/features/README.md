# Funcionalidades

Organizar cada área funcional em pacote próprio, mantendo os componentes, hooks,
tipos e chamadas de API pertencentes a essa área juntos.

Áreas previstas pelos requisitos: `authentication`, `academic-structure`,
`materials`, `search`, `collaboration`, `moderation`, `reputation`,
`notifications` e `administration`. Criar cada pacote quando começar a ser
implementado; esta lista não significa que as funcionalidades já existam.
